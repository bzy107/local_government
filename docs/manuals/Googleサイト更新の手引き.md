# Googleサイト更新の手引き

― 回覧板ページの更新方法 ―

> 📌 この手引きは、パソコンの操作にあまり慣れていない方でも、町会のホームページ（Googleサイト）を迷わず更新できるように作成したものです。わからないところがあっても大丈夫です。無理に一人で進めようとせず、困ったときは最後にある相談先までご連絡ください。
>
> 本文中の `［　］` で囲まれた部分には、あとで実際の画面のスクリーンショット（写真）を貼り付けてください。内容を確認・修正して「完璧」になったら、この文書をもとにWord版（配布・共有用）を作成します。
>
> ⚠️ ボタンの名前や画面の配置は、実際にGoogleサイトを操作しながら確認し、現在の画面と違う場合は書き換えてください。Googleサイトの画面は予告なく変更されることがあります。

## この手引きについて

| 項目 | 内容 |
| -- | -- |
| 対象読者 | パソコンでのメール操作程度はできるが、Googleサイトの操作は初めての方 |
| 対象作業 | 町会ホームページの「回覧板」ページに、新しいお知らせを1件追加して公開するまで（編集権限はすでに付与されている前提） |
| 完了の目安 | 「公開」ボタンを押し、実際のホームページのURLで更新内容が表示されていることを確認したら完了です |
| 所要時間の目安 | 15〜20分程度（PDFのアップロードから公開の確認まで） |

## 1. 作業前に確認すること：ご自身のアカウントに権限が付与されているか確認する

この手引きは、事前に管理者から「町会ホームページ編集用」としてご自身のGoogleアカウントへの共有（アクセス権限の付与）を受けていることを前提としています。まだ権限を受けていない場合は、作業を始める前に管理者へご連絡ください。Googleアカウントをまだお持ちでない場合は、「[1-1　Googleアカウントをお持ちでない場合](#1-作業前に確認することご自身のアカウントに権限が付与されているか確認する)」を参照してください。

町会ホームページの更新は、共有の専用アカウントではなく、担当者それぞれのGoogleアカウントにアクセス権限を付与して行います。作業を始める前に、ご自身のGoogleアカウントで「町会ホームページ」フォルダにアクセスできる状態になっているか確認してください。

### 1-1　Googleアカウントをお持ちでない場合

Googleアカウントをまだお持ちでない方は、先にアカウントを作成してください。作成後、管理者に町会ホームページ編集用としてアクセス権限の付与を依頼します。

1. ブラウザで [Googleアカウントの作成ページ](https://accounts.google.com/signup) を開きます。
2. 「姓」「名」を入力し、「次へ」をクリックします。
3. 「ユーザー名」（今後のメールアドレスになります）を入力します。すでに使われている場合は、別のユーザー名を入力します。
4. 「パスワード」を入力し、確認のためもう一度入力します。
5. 画面の案内に従って、電話番号や生年月日などの情報を入力し、「次へ」をクリックします。
6. 利用規約とプライバシーポリシーを確認し、「同意する」をクリックすると、アカウントの作成が完了します。
7. 作成したメールアドレスを管理者に伝え、町会ホームページ編集用としてアクセス権限の付与を依頼します。

［ここにスクリーンショットを挿入：Googleアカウント作成画面］

すでにGoogleアカウントをお持ちの方は、次の「1-2」に進んでください。

### 1-2　アクセス権限が付与されているか確認する

1. パソコンのインターネットブラウザ（Google Chromeなど）を開き、ご自身のGoogleアカウントでログインします。
2. 複数のGoogleアカウントをお持ちの場合は、権限を付与されているアカウントに切り替えます。（切り替え方は「[2-1](#2-googleの基本的な操作方法)」を参照）
3. ブラウザのアドレス欄に「drive.google.com」と入力し、Enterキーを押します。
4. 画面上部の検索欄に「町会ホームページ」と入力し、フォルダが表示されるか確認します。
5. フォルダが表示されれば、アクセス権限は付与されています。次の作業に進んでください。
6. フォルダが見つからない場合や「アクセス権がありません」と表示される場合は、担当者に連絡し、ご自身のアカウントへの権限付与を依頼してください。

## 2. Googleの基本的な操作方法

この先の手順でよく使うGoogleの基本的な操作を確認しておきましょう。

### 2-1　アカウントの切り替え方

1. 画面右上のアイコンをクリックします。
2. 表示された一覧から、切り替えたいアカウントを選びます。
3. 一覧にない場合は「別のアカウントを追加」からログインします。

### 2-2　Googleドライブの基本操作

- フォルダを開く：フォルダの名前をダブルクリックします。
- ファイルを探す：画面上部の検索欄にファイル名の一部を入力します。
- 前の画面に戻る：画面左上の「マイドライブ」など、上の階層の名前をクリックします。

### 2-3　用語集（やさしい言葉での説明）

- 共有：他の人がそのファイルを見られるようにすること。
- 公開：編集した内容を、実際のホームページに反映させること。
- 下書き：まだ公開されていない、編集中の状態のこと。
- リンク：クリックすると別のページやファイルが開く、文字や画像のこと。

## 3. PDFデータのアップロード（共有設定）

### 3-1　Googleドライブを開く

1. ブラウザのアドレス欄に「drive.google.com」と入力し、Enterキーを押します。
2. ご自身のアカウント（アクセス権限が付与されているアカウント）でログインしていることを確認します（「[1](#1-作業前に確認することご自身のアカウントに権限が付与されているか確認する)」の手順を参照）。

### 3-2　保存先フォルダを開く

1. 画面左側の一覧から「回覧板」フォルダをクリックして開きます。

［ここにスクリーンショットを挿入：回覧板フォルダの一覧］

### 3-3　PDFファイルをアップロードする

**方法A：ドラッグ＆ドロップする場合**

1. パソコンの中にある回覧物のPDFファイルを、マウスでつかんだままGoogleドライブの画面まで動かします。
2. 画面の上でマウスのボタンを離すと、アップロードが始まります。

**方法B：「＋新規」ボタンを使う場合**

1. 画面左上の「＋新規」ボタンをクリックします。
2. 「ファイルのアップロード」を選びます。
3. アップロードしたいPDFファイルを選んで「開く」をクリックします。

［ここにスクリーンショットを挿入：PDFアップロードの手順］

### 3-4　共有設定をする

アップロードしただけでは、まだ他の人はPDFを見ることができません。次の手順で「誰でも見られる」設定に変更します。

1. アップロードしたPDFファイルを右クリックします。
2. 「共有」を選びます。
3. 「制限付き」と書かれた部分をクリックし、「リンクを知っている全員」に変更します。
4. 権限が「閲覧者」になっていることを確認します。（誤って「編集者」にしないよう注意してください）
5. 「完了」または「コピー」をクリックします。

［ここにスクリーンショットを挿入：共有設定の画面］

### 3-5　共有設定を間違えたときの直し方

1. もう一度ファイルを右クリックし、「共有」を選びます。
2. 「アクセスを管理」から設定を選び直します。
3. わからないときは無理をせず、担当者に相談してください。

## 4. PDFデータへのリンク

### 4-1　共有リンクをコピーする

1. アップロードしたPDFファイルを右クリックします。
2. 「共有」→「リンクをコピー」の順にクリックします。

［ここにスクリーンショットを挿入：リンクのコピー］

### 4-2　Googleサイトにリンクを貼り付ける

1. Googleサイトの編集画面を開きます。（開き方は「[5. 回覧板ページの更新方法](#5-回覧板ページの更新方法)」を参照）
2. リンクを貼りたい場所（お知らせのタイトルなど）をクリックして選びます。
3. 選択すると表示される小さなメニューから「リンク」を選びます。
4. 先ほどコピーしたリンクを貼り付け、「適用」をクリックします。

［ここにスクリーンショットを挿入：リンクの挿入画面］

### 4-3　リンクの表示名をわかりやすくする

1. リンクを貼った文字を、内容がひと目でわかる名前に書き換えます。（例：「〇月〇日　防災訓練のお知らせ」）

### 4-4　リンクが正しく開くか確認する

1. 貼り付けたリンクを実際にクリックし、PDFが正しく開くか確認します。
2. 開かない場合は、「[3-4　共有設定をする](#3-pdfデータのアップロード共有設定)」をもう一度見直してください。

## 5. 回覧板ページの更新方法

### 5-1　編集画面を開く

1. ブラウザで「sites.google.com」を開きます。ご自身のアカウント（アクセス権限が付与されているアカウント）でログインしていることを確認してください。
2. 更新するサイトを選んで開きます。
3. 画面右上の鉛筆マーク（編集ボタン）をクリックします。

［ここにスクリーンショットを挿入：編集画面の開き方］

### 5-2　新しいお知らせを追加する

1. 左側のメニューから「回覧板」ページに移動します。
2. お知らせ一覧の一番上に、新しい項目を追加します。
3. 掲載日（例：2026年8月24日）とタイトルを入力します。
4. 「[4. PDFデータへのリンク](#4-pdfデータへのリンク)」の手順でPDFへのリンクを設定します。

### 5-3　並び順を確認する

1. 新しく追加したお知らせが、一覧の一番上（最新）に来ているか確認します。
2. 順番が違う場合は、項目をドラッグして並び替えます。

### 5-4　公開する

編集した内容は、「公開」ボタンを押さないと実際のホームページには反映されません。最後に必ず公開の手順を行ってください。

1. 画面右上の「公開」ボタンをクリックします。
2. 確認画面が表示されたら、内容を確認して「公開」を選びます。

## 6. 更新を取り消したい場合

### 6-1　誤って公開してしまったとき

1. あわてず、まずはそのままの状態にしておいてください。
2. 下記「6-2」の手順で元に戻すか、担当者に連絡してください。

### 6-2　変更履歴から元に戻す

1. 編集画面の右上にある「その他の操作」（縦に3つ並んだ点のマーク）をクリックします。
2. 「変更履歴を確認」を選びます。
3. 戻したい時点を選んで「この版を復元」をクリックします。

## 7. よくあるつまずきと対処

| 症状 | 考えられる原因 | 対処 |
| -- | -- | -- |
| 編集できない・鉛筆マークが出ない | ご自身のアカウントに編集権限が付与されていない、または権限のない別のアカウントでログインしている | 「[1. 作業前に確認すること](#1-作業前に確認することご自身のアカウントに権限が付与されているか確認する)」に沿ってアカウントを確認する。権限がない場合は担当者に相談する |
| PDFのリンクをクリックしても開かない・「アクセス権がありません」と表示される | 共有設定が「制限付き」のままになっている | 「[3-4　共有設定をする](#3-pdfデータのアップロード共有設定)」をもう一度行う |
| 「公開」を押したのにホームページに反映されない | ブラウザにキャッシュ（古い表示）が残っている、または公開の操作が完了していない | 数分待ってからページを再読み込みする。改善しない場合は「5-4　公開する」の手順をやり直す |
| 間違った内容のまま公開してしまった | 公開前の確認不足 | あわてず「[6. 更新を取り消したい場合](#6-更新を取り消したい場合)」の手順で元に戻す |

## 8. 気を付けること（アカウントの確認）

1. 作業を始める前に、必ず画面右上のアイコンをクリックし、権限を付与されているご自身のアカウントでログインしているか確認します。
2. 複数のGoogleアカウントをお持ちの場合、権限のない別のアカウントのままでは「町会ホームページ」フォルダやサイトが表示されなかったり、編集できなかったりします。
3. 見分け方：アイコンにマウスを合わせると、メールアドレスが表示されます。権限を付与されているご自身のアドレスになっているか確認してください。
