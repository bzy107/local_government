# LINE公式アカウント配信の手引き

― 町会からのお知らせを配信する方法 ―

> 📌 この手引きは、スマートフォンでLINEを使ったことはあるが、LINE公式アカウントの操作は初めてという方でも、町会の公式アカウントから迷わずお知らせを配信できるように作成したものです。わからないところがあっても大丈夫です。無理に一人で進めようとせず、困ったときは最後にある管理者の連絡先までご連絡ください。
>
> 本文中の `［　］` で囲まれた部分には、あとで実際の画面のスクリーンショット（写真）を貼り付けてください。内容を確認・修正して「完璧」になったら、この文書をもとにWord版（配布・共有用）を作成します。
>
> ⚠️ ボタンの名前や画面の配置は、実際にLINE公式アカウントを操作しながら確認し、現在の画面と違う場合は書き換えてください。LINE公式アカウントの画面や料金プランは予告なく変更されることがあります。

## この手引きについて

| 項目 | 内容 |
| -- | -- |
| 対象読者 | スマートフォンでLINEのやり取りはできるが、LINE公式アカウント（配信側）の操作は初めての方 |

## 1. 作業前に確認すること：ご自身のLINEアカウントに権限が付与されているか確認する

この手引きは、事前に管理者から町会のLINE公式アカウントの「運用担当者」または「管理者」として、ご自身のLINEアカウントに権限を付与されていることを前提としています。まだ権限を受けていない場合は、作業を始める前に管理者へご連絡ください。

町会のLINE公式アカウントは、共有のID・パスワードを回して使うのではなく、担当者それぞれの個人のLINEアカウントに権限を付与して操作します。ご自身のLINEアカウントでログインすれば、町会のアカウントとして配信できます。町会員から見えるのは「町会の公式アカウント」の名前だけで、担当者個人の名前やアカウントは表示されません。

この手引きに出てくる人の呼び方は、次のとおりです。

- **担当者**：この手引きを読んで配信作業を行う方（あなた）のことです。
- **管理者**：LINE公式アカウントの権限やプランの管理を行う人です。操作でわからないことがあるときの相談先でもあります。連絡先は末尾の「[困ったときは](#困ったときは)」に記入してあります。

> ℹ️ ご自身のLINEの表示名（プロフィールの名前）は、管理者が「権限管理」の画面で担当者を見分けるために使います。町会員には表示されませんので、ニックネームにしている方は、本名（例：「沢村 太郎」）に設定していただけると助かります。

### 1-1　権限の種類

LINE公式アカウントには、次のような権限の種類があります。お知らせの配信には「管理者」または「運用担当者」の権限が必要です。

| 権限の種類 | できること |
| -- | -- |
| 管理者 | すべての操作（配信・設定変更・メンバーの追加や削除） |
| 運用担当者 | お知らせの配信・チャットの返信・分析の閲覧 |
| 運用担当者（配信権限なし） | チャットの返信・分析の閲覧のみ。**お知らせの配信はできません** |
| 運用担当者（分析の閲覧権限なし） | お知らせの配信・チャットの返信 |

> ℹ️ 表の「チャットの返信」はLINE公式アカウントの機能の説明です。町会ではチャットの返信は使いません（「[9-5](#9-気を付けること)」参照）。

### 1-2　権限が付与されているか確認する（スマートフォン）

1. スマートフォンに「LINE公式アカウント」アプリ（緑色のアイコン。普段使っている「LINE」アプリとは別のアプリです）をインストールします。
   - iPhoneの方はApp Store、Androidの方はGoogle Playで「LINE公式アカウント」と検索してください。
2. アプリを開き、「LINEアプリでログイン」をタップします。
3. 普段使っているご自身のLINEアカウントでログインします。
4. 画面に町会のアカウント名（沢村町会）が表示されれば、権限は付与されています。次の作業に進んでください。
5. 町会のアカウントが表示されない場合は、管理者に連絡し、ご自身のLINEアカウントへの権限付与を依頼してください。

［ここにスクリーンショットを挿入：LINE公式アカウントアプリのログイン画面とアカウント一覧］

### 1-3　権限が付与されているか確認する（パソコン）

1. パソコンのGoogle Chromeで [LINE Official Account Manager](https://manager.line.biz/) を開きます。
2. 「LINEアカウントでログイン」をクリックします。
3. 画面の案内に従い、普段使っているご自身のLINEアカウントでログインします。（QRコードが表示された場合は、スマートフォンのLINEアプリでQRコードを読み取るとログインできます）
4. アカウント一覧に町会のアカウント名（沢村町会）が表示されれば、権限は付与されています。
5. 表示されない場合は、管理者に連絡し、ご自身のLINEアカウントへの権限付与を依頼してください。

［ここにスクリーンショットを挿入：LINE Official Account Managerのログイン画面とアカウント一覧］

### 1-4　町会の公式アカウントを友だち追加する

テスト配信や本配信のメッセージは、ご自身が町会の公式アカウントを「友だち追加」していないと、ご自身のLINEには届きません。配信内容を確認するために、作業を始める前に必ず友だち追加しておいてください。

1. 管理者から、町会の公式アカウントの友だち追加用のQRコード（またはリンク）を受け取ります。（ホームページや回覧板に掲載しているものでも構いません）
2. スマートフォンの「LINE」アプリ（普段使っているアプリ）を開き、ホーム画面右上の「友だち追加」（人型に＋のマーク）をタップします。
3. 「QRコード」をタップし、QRコードを読み取ります。（リンクを受け取った場合は、リンクをタップします）
4. 町会の公式アカウント（沢村町会）が表示されたら、「追加」をタップします。
5. トーク一覧に町会のアカウントが表示されれば完了です。

> ⚠️ 町会のアカウントをブロックしていると、権限があってもメッセージは届きません。過去にブロックした覚えがある方は、LINEアプリの「設定」→「友だち」→「ブロックリスト」を確認し、解除してください。

［ここにスクリーンショットを挿入：友だち追加のQRコード読み取り画面］

### 1-5　管理者向け：担当者の権限を付与・削除する方法

この項目は管理者が行う作業です。担当者の方は読み飛ばして構いません。

1. パソコンでLINE Official Account Managerを開き、町会のアカウントを選びます。
2. 画面右上の「設定」をクリックします。
3. 左側のメニューから「権限管理」を選びます。
4. 「メンバーを追加」をクリックします。
5. 権限の種類（通常は「運用担当者」）を選び、「URLを発行」をクリックします。
6. 表示されたURLをコピーし、新しい担当者にLINEやメールで送ります。
7. 担当者がそのURLをスマートフォンで開き、ご自身のLINEアカウントでログインすると、権限の付与が完了します。

> ⚠️ 発行したURLには有効期限があります。URLを受け取った担当者には、なるべく早く開いてもらってください。

管理者は以下スプレッドシートにも運用者を記入してください。運用から外れた方はステータスを削除済みにしてください。
https://docs.google.com/spreadsheets/d/12mWLXdCNVS13exHtAAo73m-kGkTm-CaQEvqukZyoYvg/edit?usp=drive_link

**担当を外れた人の権限を削除する**

役員の交代などで担当を外れた人は、配信ができないように権限を削除します。削除するのは町会アカウントに対する権限だけで、その人の個人のLINEアカウントが消えるわけではありません。

1. パソコンでLINE Official Account Managerを開き、町会のアカウントを選びます。
2. 画面右上の「設定」をクリックします。
3. 左側のメニューから「権限管理」を選びます。
4. メンバーの一覧から、担当を外れた人の名前を探します。
5. その人の行の右側にある「削除」をクリックします。
6. 確認画面が表示されたら「削除」を選びます。一覧から名前が消えれば完了です。

> ℹ️ 担当の交代があったら、引き継ぎが済み次第すみやかに削除してください。権限が残ったままだと、担当を外れた人が誤って配信してしまうおそれがあります。

**緊急時に料金プランを変更する**

災害時などに配信数が月5,000通の上限に達してしまった場合は、管理者が一つ上のスタンダードプラン（月30,000通）に変更します。月の途中でも変更したその日から反映されます。

1. パソコンでLINE Official Account Managerを開き、町会のアカウントを選びます。
2. 画面右上の「設定」をクリックします。
3. 左側のメニューから「利用と請求」→「月額プラン」を選びます。
4. 「プランを変更」をクリックし、「スタンダードプラン」を選びます。
5. 表示される料金と反映日を確認し、「変更」を選びます。

> ⚠️ 上位プランへの変更には、支払い方法（クレジットカードなど）が登録されている必要があります。緊急時に慌てないよう、平常時に登録されているか確認しておいてください。緊急対応が終わったら、翌月からライトプランに戻す変更も忘れずに行ってください（下位プランへの変更は翌月1日から反映されます）。

## 2. LINE公式アカウントの基本

### 2-1　LINE公式アカウントとは

LINE公式アカウントとは、お店や団体が、友だち登録してくれた人たちにまとめてメッセージを送るための仕組みです。町会では、回覧板やホームページの更新のお知らせ、行事の案内、災害時の緊急情報などを町会員のスマートフォンへ直接届けるために使います。

普段使っている「LINE」アプリは、友だち一人ひとりとやり取りをするためのものです。町会からお知らせを配信するときは、それとは別の「LINE公式アカウント」アプリ（または、パソコンの管理画面）を使います。

### 2-2　操作する画面は2種類ある

町会のアカウントを操作する方法は2つあります。どちらで行っても結果は同じです。

| 方法 | 向いている場面 |
| -- | -- |
| パソコン（LINE Official Account Manager） | 長めの文章をじっくり作るとき。画面が大きく見やすく、テスト配信もしやすいので、**この手引きではパソコンでの操作を基本としてご案内します** |
| スマートフォン（LINE公式アカウントアプリ） | 外出先などで急いで短いお知らせを送るとき。災害時など、パソコンが使えない場面 |

### 2-3　配信できるメッセージの数には上限がある

LINE公式アカウントには料金プランがあり、どのプランでも **1か月に配信できるメッセージの数に上限があります。** 町会では、月5,000通まで配信できる有料のプラン（ライトプラン）に加入しています。

- 配信数は「**1回の配信で届く人数 × 配信した回数**」で数えます。例えば、友だちが100人いるアカウントで1回配信すると、100通を使ったことになります。
- 町会のプランの上限は **月5,000通** です。友だちが100人であれば、1か月に50回まで配信できる計算になり、通常の運用で上限に達することはまずありません。（参考：無料のプランでは月200通が上限で、友だちが100人なら月2回しか配信できません）
- 上限に達すると、その月はそれ以上配信できなくなります。ただし、月5,000通の枠は通常の運用では使い切れないほど余裕があります。**お知らせしたいことがあれば、配信数を気にせず活用してください。** 使わずに余らせてしまう方がもったいないです。
- **災害時などの緊急情報は、配信数の上限を気にせず配信してください。** 万一上限に達してしまった場合は、管理者が一つ上のプラン（スタンダードプラン、月30,000通まで）に変更すれば、その日のうちに配信を再開できます。上限に達した、または達しそうなときは、すぐに管理者に連絡してください。

> ⚠️ 上限の数や料金プランの内容は変更されることがあります。今月の配信数は管理画面の「ホーム」で確認できます。プランの変更が必要と思われる場合は、管理者にご相談ください。

### 2-4　用語集（LINE公式アカウントでよく使う言葉）

- **友だち**：町会の公式アカウントを登録してくれた町会員のこと。配信したメッセージは、友だち全員に届きます。
- **メッセージ配信**：友だち全員にまとめてメッセージを送ること。この手引きの主な作業です。
- **配信予約**：日時を指定して、あとから自動的に配信されるようにすること。
- **テスト配信**：本番の配信をする前に、操作しているご自身のLINEだけにメッセージを送って、見え方を確認すること。友だちには届きません。
- **下書き**：作りかけのメッセージを、まだ配信せずに保存しておくこと。
- **チャット**：町会員から公式アカウントに送られてきたメッセージが届く場所。町会では原則として返信には使いません（「[9-5](#9-気を付けること)」参照）。
- **ターゲットリーチ**：配信が届く人数のこと。配信数の計算に使われます。

## 3. 配信する前に決めておくこと

配信は、一度送ると取り消すことができません（「[7. 配信を取り消したい場合・間違えたとき](#7-配信を取り消したい場合間違えたとき)」参照）。画面の操作を始める前に、次のことを紙やメモに書き出しておくと、落ち着いて作業できます。

### 3-1　配信の承認

- **通常のお知らせ**（回覧板の更新・行事の案内など）：担当者の判断で配信して構いません。
- **緊急情報**（災害時の避難情報・安否確認フォームの配信など）：**町会長の指示（災害対策本部での合意）を受けてから配信します。** 担当者の独断では配信しないでください。詳しくはホームページの「町会役員の対応」ページを参照してください。

### 3-2　配信する内容を決める

次の3点を先に決めておきます。

1. **何を伝えるか**（例：回覧板の新しいお知らせ、○月○日の防災訓練の案内）
2. **どこに詳しい情報があるか**（例：ホームページの回覧板ページのURL、Googleドライブの共有リンク）
3. **いつ配信するか**（今すぐ送るか、日時を予約するか）

### 3-3　PDFやWordファイルは直接送れない

LINE公式アカウントの配信では、PDFやWordなどのファイルを添付して送ることはできません（写真・画像は送れます）。回覧物などのファイルを町会員に見てもらうときは、次の手順で行います。

1. 先に、ファイルをホームページ（回覧板ページ）に掲載します。（手順は別冊「Googleサイト更新の手引き」を参照）
2. ホームページの回覧板ページのURL（またはGoogleドライブの共有リンク）を、LINEの文章の中に貼り付けて配信します。

こうすることで、町会員はLINEのメッセージにあるリンクをタップするだけで、ホームページ上のファイルを見ることができます。

### 3-4　文章を先に用意しておく

配信する文章は、管理画面の中で直接打ち込むよりも、先にメモ帳やWordなどで作ってから貼り付ける方が、落ち着いて確認できて安全です。文章の書き方と例文は「[6. 配信する文章の書き方と例文](#6-配信する文章の書き方と例文)」を参照してください。

## 4. お知らせを配信する（パソコンで行う場合）

### 4-1　管理画面を開く

1. パソコンのGoogle Chromeで [LINE Official Account Manager](https://manager.line.biz/) を開きます。
2. 「LINEアカウントでログイン」をクリックし、ご自身のLINEアカウントでログインします。（「[1-3](#1-作業前に確認することご自身のlineアカウントに権限が付与されているか確認する)」の手順を参照）
3. アカウント一覧から町会のアカウント名（沢村町会）をクリックします。
4. 「ホーム」画面が表示されます。

［ここにスクリーンショットを挿入：ホーム画面］

### 4-2　新しいメッセージを作る

1. 画面左側のメニューから「メッセージ配信」をクリックします。
2. 画面右上の「作成」ボタンをクリックします。

［ここにスクリーンショットを挿入：メッセージ配信の一覧画面と「作成」ボタン］

### 4-3　配信先と配信日時を設定する

1. 「配信先」が「すべての友だち」になっていることを確認します。（町会では通常、絞り込みは行いません）
2. 「配信日時」を選びます。
   - 今すぐ送る場合：「今すぐ配信」を選びます。
   - 日時を決めて送る場合：「配信日時を指定」を選び、日付と時刻を入力します。（例：行事の前日の午前10時）
3. 「高度な設定」の中の「LINE VOOMに投稿」にチェックが入っている場合は、**チェックを外します。**（町会のお知らせを、友だち以外の人にも公開する必要はないためです）

［ここにスクリーンショットを挿入：配信先・配信日時の設定画面］

### 4-4　文章を入力する

1. 画面下の「テキスト」（吹き出しのマーク）をクリックします。
2. 表示された入力欄に、用意しておいた文章を貼り付けます。（メモ帳などで文章を選んでコピー（Ctrl＋C）し、入力欄をクリックしてから貼り付け（Ctrl＋V）します）
3. ホームページなどのリンクを入れる場合は、URLをそのまま文章の中に貼り付けます。配信されると、URLは自動的にタップできるリンクになります。
4. 文章の下に表示されている文字数を確認します。長すぎる場合は、要点だけを残して、詳しくはホームページを見てもらうようにします。

> ℹ️ 1回の配信で送れる吹き出しは3つまでです。写真を添えたい場合は「追加」をクリックして、2つ目の吹き出しに「画像」を選んでアップロードします。通常のお知らせは、文章の吹き出し1つで十分です。

［ここにスクリーンショットを挿入：テキスト入力画面］

### 4-5　テスト配信をして見え方を確認する

本番の配信をする前に、必ずテスト配信を行います。テスト配信は操作しているご自身のLINEだけに届き、友だち（町会員）には届きません。また、配信数にも数えられません。（ご自身が町会のアカウントを友だち追加していないと届きません。「1-4」を参照）

1. 画面右上の「テスト配信」をクリックします。
2. 届け先を選ぶ画面が表示されるので、「自分のみ」を選び、「配信」をクリックします。（「すべての管理者と運用担当者」を選ぶと、他の担当者のLINEにも届きます）
3. ご自身のスマートフォンのLINEを開き、町会のアカウントからメッセージが届いていることを確認します。
4. 次の点を確認します。
   - 誤字・脱字がないか、日付や場所が正しいか
   - リンクをタップすると、正しいページが開くか
   - 改行が変なところで入っていないか
5. 直す箇所があれば、パソコンの画面に戻って修正し、もう一度テスト配信をします。

［ここにスクリーンショットを挿入：テスト配信ボタンと、スマートフォンに届いたテストメッセージ］

### 4-6　本番の配信をする

1. テスト配信で問題がないことを確認したら、画面右上の「配信」ボタンをクリックします。（配信日時を指定した場合は「配信予約」ボタンになります）
2. 確認画面が表示されます。配信先の人数と内容をもう一度確認し、「配信」をクリックします。
3. 「メッセージ配信」の一覧画面に戻り、今作ったメッセージが「配信済み」（予約の場合は「配信予約」）と表示されていることを確認します。
4. ご自身のスマートフォンのLINEで、町会のアカウントからメッセージが届いていることを確認します。

［ここにスクリーンショットを挿入：配信の確認画面と、配信済みの一覧］

これで配信は完了です。

### 4-7　途中で作業をやめたいとき（下書き保存）

文章を作りかけのまま、あとで続きを行いたいときは、画面右上の「下書き保存」をクリックします。「メッセージ配信」の一覧画面で「下書き」と表示されているものをクリックすると、続きから作業できます。

## 5. お知らせを配信する（スマートフォンで行う場合）

外出先や災害時など、パソコンが使えないときはスマートフォンの「LINE公式アカウント」アプリから配信できます。手順の流れはパソコンの場合と同じです。

### 5-1　アプリを開く

1. スマートフォンの「LINE公式アカウント」アプリを開きます。（普段使っている「LINE」アプリではありません）
2. 町会のアカウント名（沢村町会）をタップします。

［ここにスクリーンショットを挿入：アプリのホーム画面］

### 5-2　メッセージを作って配信する

1. ホーム画面の「メッセージ配信」をタップします。（見つからない場合は、画面下の「作成」または「＋」をタップしてください）
2. 「配信先」が「すべての友だち」になっていることを確認します。
3. 「配信日時」で「今すぐ配信」または日時の指定を選びます。
4. 「LINE VOOMに投稿」がオンになっている場合は、オフにします。
5. 「テキスト」をタップし、文章を入力（または貼り付け）します。
6. 「テスト配信」をタップし、ご自身のLINEに届いたメッセージで、誤字やリンクを確認します。
7. 問題がなければ「配信」をタップし、確認画面で内容を確認して、もう一度「配信」をタップします。

［ここにスクリーンショットを挿入：アプリのメッセージ作成画面と配信ボタン］

> ℹ️ スマートフォンでは画面が小さく、文章の確認が難しいことがあります。急ぎでない通常のお知らせは、できるだけパソコンから配信することをおすすめします。

## 6. 配信する文章の書き方と例文

### 6-1　書き方のポイント

1. **1行目で何のお知らせかがわかるようにする。** 通知に表示されるのは最初の1〜2行だけなので、ここで内容が伝わるようにします。書き方は決まっていません。例文のように「〜のお知らせ」としてもよいですし、ご自身の書きやすい形で構いません。
2. **短くまとめる。** スマートフォンの画面で、スクロールせずに読める長さ（10行程度）を目安にします。詳しい内容はホームページに載せ、そのページの URL を文章に貼るか、トーク画面の下にあるメニュー（リッチメニュー）の「回覧板」「町会行事」などのタイルを案内します。例文はタイルを案内する形で書いています。
3. **日付・時刻・場所は必ず書く。** 「明日」「来週」ではなく、「9月20日（日）」のように具体的に書きます。
4. **個人情報は書かない。** 町会員の氏名・住所・電話番号などは、配信に含めないでください。
5. **絵文字や記号は控えめに。** 装飾が多いと、高齢の方には読みにくくなります。

### 6-2　例文：回覧板の更新のお知らせ

```
回覧板を更新しました

ホームページの回覧板に、次のお知らせを掲載しました。

・9月20日（日）防災訓練のご案内
・10月の資源回収日程

下記のメニューの「回覧板」のタイルをタップしてホームページから確認してください。
```

### 6-3　例文：行事の案内

```
防災訓練のご案内

日時：9月20日（日）午前9時〜11時
場所：○○公園（雨天時は○○会館）
内容：初期消火訓練・炊き出し体験
持ち物：軍手・飲み物

どなたでも参加できます。ぜひお越しください。

下記のメニューの「町会行事」のタイルをタップしてホームページから確認してください。
```

## 7. 配信を取り消したい場合・間違えたとき

### 7-1　配信予約を取り消す（まだ配信されていない場合）

配信日時を指定して予約した場合は、配信される前であれば取り消せます。

1. 「メッセージ配信」の一覧画面を開きます。
2. 「配信予約」のタブを開き、取り消したいメッセージを探します。
3. そのメッセージの右側にある「削除」（ゴミ箱のマーク）をクリックします。
4. 確認画面が表示されたら「削除」を選び、一覧から消えたことを確認します。

> ℹ️ 文章を残して日時だけ変えたい場合は、「削除」ではなく「編集」（鉛筆のマーク）を開き、配信日時を直して「配信予約」し直すか、「下書き保存」してください。

［ここにスクリーンショットを挿入：配信予約の取り消し画面］

### 7-2　すでに配信してしまった場合

**一度配信したメッセージは、取り消したり、町会員のLINEから消したりすることはできません。** 誤った内容を配信してしまった場合は、次のように対応します。

1. あわてず、どこが間違っていたかを確認します。
2. 訂正のメッセージを配信します。訂正は「どこが間違っていたか」と「正しい内容」を短く書きます。

```
訂正のお知らせ

先ほど配信した防災訓練の案内に誤りがありました。
お詫びして訂正いたします。

誤：9月20日（土）
正：9月20日（日）

場所・時間に変更はありません。
```

> ⚠️ 訂正の配信が何度も続くと、どれが正しい情報なのか読む側が混乱してしまいます。日時や場所など、町会員の行動に関わる誤りは必ず訂正を配信してください。一方で、緊急でない小さな誤り（誤字など）は、無理に訂正を配信せず、次回の配信やホームページで補足する方がよい場合もあります。

### 7-3　相談先

操作でわからないことがあれば、一人で悩まず、末尾の「[困ったときは](#困ったときは)」に記載の管理者までご連絡ください。

## 8. よくあるつまずきと対処

| 症状 | 考えられる原因 | 対処 |
| -- | -- | -- |
| ログインしても町会のアカウントが表示されない | ご自身のLINEアカウントに権限が付与されていない、または権限のない別のアカウントでログインしている | 「[1. 作業前に確認すること](#1-作業前に確認することご自身のlineアカウントに権限が付与されているか確認する)」に沿って確認する。権限がない場合は管理者に相談する |
| 「メッセージ配信」のメニューが見当たらない・「配信」ボタンが押せない | 権限が「運用担当者（配信権限なし）」になっている | 管理者に連絡し、権限の変更を依頼する |
| 「配信数の上限に達しました」などと表示されて配信できない | 今月の配信数がプランの上限（月5,000通）に達している | 管理者に連絡する。緊急の場合はすぐに上のプランへ変更してもらう（「[2-3](#2-line公式アカウントの基本)」参照） |
| テスト配信が自分のLINEに届かない | 町会の公式アカウントを友だち追加していない（またはブロックしている）、メールアドレスでログインしている（LINEアカウントと結びついていない）、または通知がオフになっている | 「[1-4　町会の公式アカウントを友だち追加する](#1-作業前に確認することご自身のlineアカウントに権限が付与されているか確認する)」の手順で友だち追加する。「LINEアカウントでログイン」からログインし直す。スマートフォンのLINEで町会のアカウントとのトーク画面を直接開いて確認する |
| 配信したメッセージのリンクをタップしても開かない・「アクセス権がありません」と表示される | Googleドライブの共有設定が「制限付き」のままになっている、またはURLの貼り付けが途中で切れている | 別冊「Googleサイト更新の手引き」の「3-4　共有設定をする」を確認する。URLを貼り直して訂正の配信を検討する |
| 配信したのに一部の町会員に届いていない | 相手が町会のアカウントをブロックしている、または友だち登録していない | 配信の仕組み上、届けることはできない。回覧板やホームページなど別の方法でも案内する |
| LINE VOOMにお知らせが投稿されてしまった | 「LINE VOOMに投稿」のチェックを外し忘れた | 管理画面の「LINE VOOM」から該当の投稿を削除する。次回からチェックを外す |

## 9. 気を付けること

### 9-1　配信する前の最終確認（チェックリスト）

「配信」ボタンを押す前に、次の項目をすべて確認してください。

- [ ] （緊急情報の場合）町会長の指示を受けている
- [ ] （念のため）「ホーム」画面の「今月の配信数」が上限（5,000通）に達していない
- [ ] 配信先が「すべての友だち」になっている
- [ ] 「LINE VOOMに投稿」のチェックが外れている
- [ ] 日付・時刻・場所・電話番号が正しい
- [ ] （URL を入れた場合）リンクをタップして、正しいページが開くことをテスト配信で確認した
- [ ] 個人情報（町会員の氏名・住所・電話番号など）が含まれていない
- [ ] 配信日時（今すぐ／予約）が意図したとおりになっている

### 9-2　アカウントの確認

1. 作業を始める前に、必ず操作しているアカウントが町会のアカウント（沢村町会）になっているか確認します。
2. 複数のLINE公式アカウントの権限をお持ちの場合（お店のアカウントなど）、別のアカウントから誤って配信してしまうことがあります。画面上部に表示されているアカウント名を確認してください。

［ここにスクリーンショットを挿入：画面上部のアカウント名の表示］

### 9-3　設定を変更しないための注意

町会のLINE公式アカウントの設定（アカウント名・プロフィール画像・あいさつメッセージ・応答設定など）は、他の役員・担当者も共通で使っています。個人の判断で設定を変更しないでください。

1. 「設定」画面の中は、この手引きの範囲では触る必要がありません。誤って変更しないよう注意してください。
2. 「友だち」の削除やブロック、権限管理の変更は管理者のみが行います。
3. 万が一設定を変えてしまった場合は、あわてずすぐに管理者に連絡してください。

### 9-4　配信の頻度と時間帯

1. 配信の回数に決まりはありません。回覧板の更新や行事の案内など、**お知らせしたいことがあれば、その都度配信してください。** 配信数の枠は十分にあるので、使わずに余らせる方がもったいないです。ただし、1通の内容は短くまとめ、読む人の負担にならないようにします（「[6. 配信する文章の書き方と例文](#6-配信する文章の書き方と例文)」参照）。
2. 配信する時間帯は、**午前9時〜午後8時**を目安にします。早朝や深夜の配信は、緊急時を除いて避けてください。
3. 緊急情報は、この限りではありません。町会長の指示に従い、必要なときにすぐ配信します。

### 9-5　町会員からの返信への対応

町会員が公式アカウントにメッセージを送ると、管理画面の「チャット」に届きます。町会では、このチャットでの返信は**原則として行いません**。

1. 配信担当の方は、チャットに返信する必要はありません。返信がなくても気にせず配信作業だけを行ってください。
2. 質問や苦情など、対応が必要そうな内容に気づいた場合は、チャットで返信せず、管理者に連絡してください。管理者が電話や回覧など別の方法で対応します。
3. チャットに届いた内容は、町会員個人からのメッセージです。内容を他の人に見せたり、配信に転載したりしないでください。
